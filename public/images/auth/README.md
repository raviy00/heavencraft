# 🎭 Auth Character Images

Place your Minecraft character images here. Two files are needed:

| File | Used On | Recommendation |
|---|---|---|
| `login.png` | Login card (left side) | Minecraft character PNG with transparent background, ~400×500px |
| `register.png` | Register card (left side) | Different pose/character, same dimensions |

> **Tip:** Use Minecraft skin renderers like [NameMC](https://namemc.com) or [mc-heads.net](https://mc-heads.net) to generate character renders.
